# 드레싱 배합 · 원가 계산기 (지중해 보울)

지중해 보울 메뉴의 드레싱 5종을 배치량(g)에 맞춰 환산하고, 재료별 배합·비중·원가를 실시간으로 보여주는 단일 페이지 계산기입니다. 노션 페이지에 임베드하거나 휴대폰에서 바로 열어 쓰도록 만들었습니다.

- 배포 주소: https://r2w8jp5hmn-cyber.github.io/bowl-dressing-calc/
- 파일: `index.html` 하나 (외부 라이브러리·CDN 없음, 오프라인 동작)
- 노션 임베드: `/embed https://r2w8jp5hmn-cyber.github.io/bowl-dressing-calc/` 또는 `/embed` → 링크 붙여넣기
- 임베드 높이: 페이지 전체 높이가 384px 폭 기준 **A안 473px / 최대(B+논갈릭) 561px**입니다. 노션 임베드 블록은 기본 320px이라 하단 가장자리의 핸들을 아래로 끌어 **약 580px 이상**으로 늘려 두면 5종 모두 위아래 잘림 없이 보입니다.

## 기능

| 항목 | 내용 |
| --- | --- |
| 드레싱 | A 구운마늘 레몬 타히니(무식초) · B 레몬 자타르 비네그레트 · C 오이 딜 요거트 · D 대추야자 후추 발사믹 · E 구운양파 토마토(비교용) |
| 토글 | A: CK 레몬파우더 / CK 레몬오일 대체 · B: 논갈릭(마늘 10g → 레몬주스 5g + 물 5g) · 레몬 제스트 생략 · C: 요거트 4통 묶음 단가(8.089 → 6.725원/g) · CK 버전(랠리쉬·건조딜, 물 2g 보정) |
| 배치량 | 슬라이더 35g ~ 2,000g (5g 단위) + 숫자 직접 입력 + 프리셋(35 / 100 / 350 / 1,000g) |
| 지표 | 배치 원가 · 실사용 가능량(도구 손실 5% 제외) · 35g 1회 원가 · 1g당 원가 · 예상 제공 인분 |
| 표 | 재료별 필요량(g) · 비중(%) · 원가(원) + 가로 막대 그래프, `표 복사`로 탭 구분 텍스트 복사 |

## 계산 규칙

- 레시피는 350g 기준으로 입력되어 있고, `배치량 ÷ 기준 총량`으로 모든 재료를 비례 환산합니다.
- 토글을 켜면 재료 구성이 바뀐 뒤 총량이 배치량과 같아지도록 다시 환산합니다(예: 레몬 제스트 1g → 레몬파우더 2g).
- 1회 원가 = `총 원가 ÷ (배치량 × 0.95) × 35g`, 제공 인분 = `배치량 × 0.95 ÷ 35` (소수 1자리, 350g 기준 9.5회분).

## 단가 메모

단가는 `index.html` 안 `D` 배열의 `r(재료명, g, 원/g)` 값입니다. 시세가 바뀌면 이 숫자만 고치면 되고, 토글 대체 재료의 단가도 같은 자리에 있습니다.
